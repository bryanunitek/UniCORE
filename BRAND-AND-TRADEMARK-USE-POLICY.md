## Why this file is short

The canonical `BRAND-AND-TRADEMARK-USE-POLICY.md` for the UniCORE-family programmes lives in the **TrueAI Foundation** repository and is mirrored across the foundation triad (UniVERSE / TrueAI / UniCORE-AI) for consistent reading. The full text — including the badge-denial-on-military structural rule (§4.5) and the two-mechanism structure (§8: CC BY 4.0 governs the work, certification mark governs the badge) — is canonical there.

This file in the **UniCORE** repository exists to:

1. Make the policy discoverable from the UniCORE name surface.
2. Confirm that the same rule applies to the `UniCORE` name and to the open list of `UniCORE.<Industry>` classified names.
3. Cross-link to the canonical version.

## Scope extension to UniCORE

For the avoidance of doubt, the canonical policy applies in full to:

- The `UniCORE` name itself.
- The open list of `UniCORE.<Industry>` classified names (`UniCORE.Law`, `UniCORE.Healthcare`, `UniCORE.Banking`, `UniCORE.Accounting`, `UniCORE.Space-Industry`, etc., and any future entrants on the list).
- The `Powered by UniCORE AI` and `Built on the TrueAI Foundation` attribution badges, as applied to a Solution that bears a `UniCORE.<Industry>` name.

§4.5 (badge-denial-on-military-uses) and §8 (two-mechanism structure: CC BY 4.0 governs the work, certification mark governs the badge) apply identically here.

## When industry-classified sibling repos are created

When `UniCORE.Law`, `UniCORE.Healthcare`, etc. are created as their own public repositories (see `ROADMAP.md` and the certification-trigger lock 2026-05-21 12:33 UTC), each will carry its own `BRAND-AND-TRADEMARK-USE-POLICY.md` — initially as a cross-reference of this same shape, and graduated to a fuller per-classification text only if and when programme reasons require.
